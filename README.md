# المتخصصون المهنيون للإستشارات المهنية

موقع تعريفي تفاعلي لمكتب المتخصصون المهنيون للإستشارات المهنية، مبني باستخدام React وVite وTailwind CSS.

## التشغيل محليًا

المتطلبات: Node.js 20 أو أحدث.

```bash
npm install
npm run dev
```

ثم افتح العنوان الذي يظهره Vite في الطرفية.

## أوامر المشروع

```bash
npm run build    # إنشاء نسخة الإنتاج
npm run preview  # معاينة نسخة الإنتاج
npm run lint     # فحص TypeScript
```

## النشر

يحتوي المشروع على workflow جاهز للنشر إلى GitHub Pages عند الدفع إلى فرع `main` أو `master`.
فعّل GitHub Pages من إعدادات المستودع واختر **GitHub Actions** كمصدر للنشر.
